# 🚀 Agentify

A modern single-page agency dashboard built with **React, Vite, and Tailwind CSS**.
Designed with a clean UI, smooth animations, and a responsive layout.

---

## ✨ Features

* 🌙 Light & Dark mode toggle
* ⚡ Fast performance with Vite
* 🎨 Modern UI with Tailwind CSS
* 📩 Contact form with email integration
* 📱 Fully responsive design
* 🎬 Smooth animations and transitions

---

## 🛠️ Tech Stack

* **React** – UI development
* **Vite** – Build tool & dev server
* **Tailwind CSS** – Styling
* **JavaScript (ES6+)**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sivapriyanka-dev/agentify.git
cd agentify
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```
